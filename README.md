# 阻值仪 · 点位测量软件 + 通用测试平台

给电子维修工程师用的两个工具，都在这个文件夹里：

| 程序 | 用途 | 怎么启动 |
|---|---|---|
| **`main_zzy.py`** | 主力工具：选型号 → 点位图 → 测阻值 → 自动对比标红 → 保存/导出 | 双击 `main_zzy.py` |
| `main.py` | 通用测试平台：串口/电压/接口等模块化测试（另一套需求） | 双击 `main.py` |

命令行启动方式（在本文件夹打开命令行）：

```
python main_zzy.py
python main.py
```

## 一、阻值仪软件怎么用

1. **搜索型号**：左上角输入关键字（如 `真我`、`SM8650`、`苹果`），回车或点「搜索」。
2. **选择型号**：在「型号」下拉框里选中。
3. **看点位图**：中间会画出这个型号的所有脚位方框，`序号` 就是第几个脚。
   - 点方框即可选中；滚轮上下滚动，`Ctrl+滚轮` 缩放；也有「放大/缩小/适应窗口」按钮。
   - 如果有该型号的点位图图片，点「打开点位图」加载它当底图。
4. **测一个脚位**：
   - 右侧输入**实测阻值**，点「填入」→ 立即判定
   - 或点「填入并跳到下一脚」，一个接一个往下测
5. **看结果**：
   - 🟢 **绿色** = 合格 PASS
   - 🔴 **红色** = 标红 FAIL（偏差超出容差，可疑）
   - ⬜ **灰色** = 该脚位没有参考数据
   - 🟡 **黄色** = 当前选中的脚位
6. **测完保存**：「保存记录」存进数据库，「导出CSV」用 Excel 打开。

> 还没接硬件时，可以点 **「生成演示数据」** 预览标红效果。

### 判定规则（右上角「容差」可调，默认 ±30%）

- 参考值 **0 Ω** → 实测 ≤ 10 Ω 才算合格（这是接地/短路点）
- 参考值 **≥3000 Ω** → 实测 ≥ 2500 Ω 才算合格（这是开路点）
- 其它 → 实测落在 `参考 ± 客差%` 内算合格

## 三、数据从哪来（重要）

厂商原版软件用的是加密的 Access 数据库（数据库密码已隐去，不对外公开）。
我们已经用它把数据导进来了：

| 来源 | 内容 | 行数 |
|---|---|---|
| `Database2.accdb` → 来源「**参考**」 | 厂商参考阻值 | 149,445 |
| `Database1.accdb` → 来源「**我的**」 | 你自己采集的 | 25,518 |

合计 **174,963 行、2035 个型号**，存在 `data/ohm.db`。

**以后要重新导入**（比如厂商更新了数据），运行：

```
set ACCDB_PWD=<厂商Access数据库密码>
python tools\import_accdb.py "H:\阻值仪\SJB\Database1.accdb" "H:\阻值仪\SJB\Database2.accdb"
```

## 四、福禄克 Fluke 万用表（蓝牙自动读数）

除了专用阻值仪，也支持**福禄克 279 FC 等带 Fluke Connect 的万用表**通过蓝牙自动读数。

**原理**：Fluke Connect 用的是 BLE 蓝牙，协议已被社区逆向并公开
（服务基址 `b698xxxx-7562-11e2-b50d-00163e46f8fe`），本软件已实现完整解码（`core/fluke.py`）。

**怎么用（先把表连上电脑试试）：**

1. 万用表开机，打开**无线 / Fluke Connect**（屏幕出现无线图标）
2. 关掉手机上的 Fluke Connect App（避免它抢占连接）
3. 确认电脑蓝牙是开的
4. 扫描设备：

```
python tools\fluke_scan.py
```

5. 看到你的万用表后，读取实时数值：

```
python tools\fluke_read.py
```

**支持读取的信息**：数值、单位（V/A/Ω/°C…）、量程、状态（正常 / OL 超量程 / 空档）、
属性（开路 / 短路 / 蜂鸣）等。

**下一步**：把蓝牙读数接进阻值仪界面，实现"测到就自动填入 + 自动判定 + 自动跳下一脚"。

其他支持 Fluke Connect 的型号（协议相同）：3000 FC、376 FC、902 FC、t3000 FC 等。
另外 Fluke 287/289 通过 **ir3000 FC** 红外适配器也能接入。

## 六、常见问题

**Q：双击没反应？**
在文件夹空白处右键 →「在终端中打开」，输入 `python main_zzy.py` 回车。

**Q：打开点位图提示缺少 Pillow？**
运行 `pip install Pillow`（本机其实已经装好了）。

**Q：我想改判定容差？**
界面上「容差 ±%」直接调，实时生效。

**Q：想加功能/改逻辑？**
直接告诉我「我要 XXX」，我来改。
